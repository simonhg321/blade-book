# Passkeys Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sign in to blade-book with a passkey (Face ID, Touch ID, security key, or QR-to-phone on a borrowed machine): one button on the landing page, several named passkeys managed under settings.

**Architecture:** A thin wrapper `bb/passkeys.py` over py_webauthn mints challenges, builds options and verifies responses. A `passkeys` table (schema v16) stores one row per credential. The challenge rides in a browser-bound flow cookie `bb_passkey`, using the same helpers the magic-link and OIDC flows already use (moved from the auth routes module into `bb/auth.py` so the settings blueprint can use them too). Four routes: register begin/finish under `/api/settings/passkeys`, sign-in begin/finish under `/api/auth/passkey`. Verified sign-in calls the existing `auth.login`. Pages are the existing static HTML with inline JS.

**Tech Stack:** Python 3.12 / Flask / sqlite3 (no ORM), py_webauthn 3.x (`webauthn` on PyPI, pulls `cbor2` + `cryptography`), pytest, vanilla JS static pages served by Apache, gunicorn under supervisor, Playwright (scratch venv) for headless verification.

**Spec:** `docs/superpowers/specs/2026-10-19-passkeys-design.md`

2. **A sign-in from the alias host `billboard.instockornot.club`:** a passkey minted for `blade-book.com` can never verify there; begin must answer 404 before setting any cookie, so a user is not left with a dead prompt. Pinned in Task 5.

# Copyright (c) 2026 Simon SGH — blade-book.com — Licensed under the Elastic License 2.0 (see LICENSE)
"""A software WebAuthn authenticator for tests: a real P-256 key, real
authenticatorData, a `none` attestation object and real ECDSA assertions, in
the exact JSON shape a browser's PublicKeyCredential.toJSON() produces. No
mocking of py_webauthn: every test drives the library's true verification.
Knobs on assert_() exist to forge the wrong origin / challenge / sign count /
user handle so the refusal paths are exercised with otherwise-valid data."""
import base64
import hashlib
import json
import secrets
import struct

import cbor2
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.asymmetric import ec


def b64u(b):
    return base64.urlsafe_b64encode(b).rstrip(b'=').decode()


def b64u_dec(s):
    return base64.urlsafe_b64decode(s + '=' * (-len(s) % 4))


class SoftAuthenticator:
    """One credential. uv=False makes an authenticator that never verifies the user."""

    def __init__(self, rp_id, origin, uv=True):
        self.rp_id, self.origin, self.uv = rp_id, origin, uv
        self.key = ec.generate_private_key(ec.SECP256R1())
        self.credential_id = secrets.token_bytes(16)
        self.sign_count = 0
        self.user_handle = None

    def _cose_key(self):
        nums = self.key.public_key().public_numbers()
        return cbor2.dumps({1: 2, 3: -7, -1: 1,
                            -2: nums.x.to_bytes(32, 'big'), -3: nums.y.to_bytes(32, 'big')})

    def _auth_data(self, with_cred, sign_count):
        flags = 0x01 | (0x04 if self.uv else 0) | (0x40 if with_cred else 0)   # UP, UV, AT
        data = hashlib.sha256(self.rp_id.encode()).digest() + bytes([flags]) + struct.pack('>I', sign_count)
        if with_cred:
            data += (b'\x00' * 16 + struct.pack('>H', len(self.credential_id))
                     + self.credential_id + self._cose_key())
        return data

    def _client_data(self, typ, challenge_b64u, origin=None):
        return json.dumps({'type': typ, 'challenge': challenge_b64u,
                           'origin': origin or self.origin, 'crossOrigin': False}).encode()

    def register(self, options_json, user_handle=None):
        opts = json.loads(options_json)
        self.user_handle = b64u_dec(opts['user']['id']) if user_handle is None else user_handle
        cd = self._client_data('webauthn.create', opts['challenge'])
        att = cbor2.dumps({'fmt': 'none', 'attStmt': {}, 'authData': self._auth_data(True, 0)})
        return {'id': b64u(self.credential_id), 'rawId': b64u(self.credential_id),
                'type': 'public-key', 'authenticatorAttachment': 'platform',
                'response': {'clientDataJSON': b64u(cd), 'attestationObject': b64u(att),
                             'transports': ['internal']}}

    def assert_(self, options_json, sign_count=None, origin=None, challenge=None, user_handle=None):
        opts = json.loads(options_json)
        if sign_count is None:
            self.sign_count += 1
            sign_count = self.sign_count
        cd = self._client_data('webauthn.get', challenge or opts['challenge'], origin)
        ad = self._auth_data(False, sign_count)
        sig = self.key.sign(ad + hashlib.sha256(cd).digest(), ec.ECDSA(hashes.SHA256()))
        uh = self.user_handle if user_handle is None else user_handle
        return {'id': b64u(self.credential_id), 'rawId': b64u(self.credential_id),
                'type': 'public-key', 'authenticatorAttachment': 'platform',
                'response': {'clientDataJSON': b64u(cd), 'authenticatorData': b64u(ad),
                             'signature': b64u(sig), 'userHandle': b64u(uh) if uh else None}}
```

# Copyright (c) 2026 Simon SGH — blade-book.com — Licensed under the Elastic License 2.0 (see LICENSE)
"""
bb/passkeys.py — WebAuthn (passkeys) via py_webauthn, 2026-10-19.

A thin wrapper: our relying-party constants, our challenge (32 bytes from
`secrets`, i.e. os.urandom → the kernel CSPRNG; never a library default), and
one exception type. No Flask, no DB. The library is imported lazily so a box
without it still runs every other route; `available()` tells the routes to
answer 503 and the pages to hide their buttons.

Policy (spec §1): user verification REQUIRED, resident key REQUIRED,
attestation none, user handle = the integer user id as ASCII bytes.
"""
import base64
import logging
import re
import secrets
from dataclasses import dataclass
from urllib.parse import urlparse

from bb import auth

log = logging.getLogger('blade-book.passkeys')

RP_NAME = 'blade-book'
CHALLENGE_BYTES = 32
FLOW_TTL_S = 300
MAX_PASSKEYS = 10


class PasskeyError(Exception):
    """Any verification failure; args[0] is the reason (log it, show it only to the owner)."""


@dataclass
class Registered:
    credential_id: bytes
    public_key: bytes
    sign_count: int
    transports: list


def available():
    try:
        import webauthn  # noqa: F401
        return True
    except ImportError:
        return False


def rp_id():
    return urlparse(auth.base_url()).hostname


def origin():
    return auth.base_url()


def new_challenge():
    return secrets.token_bytes(CHALLENGE_BYTES)


COOKIE = 'bb_passkey'          # flow cookie carrying the challenge; set/cleared by both route modules


def encode_challenge(challenge):
    return base64.urlsafe_b64encode(challenge).rstrip(b'=').decode('ascii')


def decode_challenge(raw):
    """The cookie value back to bytes, or None for anything that is not exactly
    one of ours (absent, oversize, bad base64, wrong length)."""
    if not isinstance(raw, str) or not raw or len(raw) > 128:
        return None
    try:
        out = base64.urlsafe_b64decode(raw + '=' * (-len(raw) % 4))
    except (ValueError, TypeError):
        return None
    return out if len(out) == CHALLENGE_BYTES else None


def _user_handle(user_id):
    return str(int(user_id)).encode('ascii')


def registration_options(user_id, handle, display_name, exclude_ids, challenge):
    import webauthn
    from webauthn.helpers.structs import (AuthenticatorSelectionCriteria, PublicKeyCredentialDescriptor,
                                          ResidentKeyRequirement, UserVerificationRequirement)
    opts = webauthn.generate_registration_options(
        rp_id=rp_id(), rp_name=RP_NAME, user_id=_user_handle(user_id), user_name=handle,
        user_display_name=display_name or handle, challenge=challenge,
        authenticator_selection=AuthenticatorSelectionCriteria(
            resident_key=ResidentKeyRequirement.REQUIRED,
            user_verification=UserVerificationRequirement.REQUIRED),
        exclude_credentials=[PublicKeyCredentialDescriptor(id=cid) for cid in exclude_ids])
    return webauthn.options_to_json(opts)


def verify_registration(credential, challenge):
    import webauthn
    from webauthn.helpers.exceptions import WebAuthnException
    try:
        v = webauthn.verify_registration_response(
            credential=credential, expected_challenge=challenge, expected_rp_id=rp_id(),
            expected_origin=origin(), require_user_verification=True)
    except (WebAuthnException, ValueError, TypeError, KeyError) as e:
        raise PasskeyError(str(e) or e.__class__.__name__) from e
    transports = None
    resp = credential.get('response') if isinstance(credential, dict) else None
    if isinstance(resp, dict) and isinstance(resp.get('transports'), list):
        transports = [t for t in resp['transports'] if isinstance(t, str)][:8]
    return Registered(credential_id=v.credential_id, public_key=v.credential_public_key,
                      sign_count=v.sign_count, transports=transports)


def authentication_options(challenge):
    import webauthn
    from webauthn.helpers.structs import UserVerificationRequirement
    opts = webauthn.generate_authentication_options(
        rp_id=rp_id(), challenge=challenge, user_verification=UserVerificationRequirement.REQUIRED)
    return webauthn.options_to_json(opts)


def verify_authentication(credential, challenge, public_key, sign_count):
    """Returns the new sign count. The library refuses a count that did not
    grow when the stored one is above zero (a cloned authenticator); 0 → 0 is
    accepted because synced passkeys never count."""
    import webauthn
    from webauthn.helpers.exceptions import WebAuthnException
    try:
        v = webauthn.verify_authentication_response(
            credential=credential, expected_challenge=challenge, expected_rp_id=rp_id(),
            expected_origin=origin(), credential_public_key=public_key,
            credential_current_sign_count=int(sign_count), require_user_verification=True)
    except (WebAuthnException, ValueError, TypeError, KeyError) as e:
        raise PasskeyError(str(e) or e.__class__.__name__) from e
    return v.new_sign_count


_UA_RULES = (
    (re.compile(r'iPhone'), 'iPhone'),
    (re.compile(r'iPad'), 'iPad'),
    (re.compile(r'Android'), 'Android'),
)
_BROWSERS = (('Firefox/', 'Firefox'), ('Edg/', 'Edge'), ('Chrome/', 'Chrome'), ('Safari/', 'Safari'))

# --- flow cookies (moved here from routes/auth.py on 2026-10-19 so the settings
# blueprint can bind a passkey registration to the browser the same way) ---------

FLOW_PATH_AUTH = paths.API_PREFIX + '/auth'
FLOW_PATH_API = paths.API_PREFIX


def flow_cookie_name(name):
    """`__Host-bb_magic` / `__Host-bb_oidc` / `__Host-bb_passkey` under https, the
    bare name on plain http (where the prefix's Secure requirement can't be met,
    e.g. test runs).

    The prefix is the fix for the sibling-host hole: this app also answers on
    the alias vhost billboard.instockornot.club, so any page on another
    *.instockornot.club host could set `bb_magic` with `Domain=.instockornot.club`
    and make an attacker-minted link take the silent, already-bound path in a
    victim's browser. A browser refuses to store a `__Host-` cookie that carries
    a Domain attribute at all, so only this exact host can write it."""
    return f'__Host-{name}' if base_url().startswith('https') else name


def _flow_path(secure, path):
    # `__Host-` REQUIRES Path=/ (and Secure, and no Domain); on http we keep the
    # tighter scope the caller asked for.
    return '/' if secure else path


def set_flow_cookie(resp, name, value, max_age, path=FLOW_PATH_AUTH):
    """A browser-binding cookie for a sign-in flow (review M2). HttpOnly, and —
    because Apple's form_post callback is a cross-site POST — SameSite=None
    (which browsers only honour with Secure, hence the https check; plain-http
    test runs fall back to Lax)."""
    secure = base_url().startswith('https')
    resp.set_cookie(flow_cookie_name(name), value, max_age=max_age,
                    path=_flow_path(secure, path), httponly=True,
                    secure=secure, samesite='None' if secure else 'Lax')
    return resp


def clear_flow_cookie(resp, name, path=FLOW_PATH_AUTH):
    # the deletion Set-Cookie must itself satisfy the `__Host-` rules or the
    # browser drops it and the cookie survives
    secure = base_url().startswith('https')
    resp.delete_cookie(flow_cookie_name(name), path=_flow_path(secure, path),
                       httponly=True, secure=secure,
                       samesite='None' if secure else 'Lax')
    return resp


def flow_value(name):
    """This request's flow cookie, or None when it is absent OR sent twice.
    Two cookies of one name means something is shadowing the real one (a
    sibling host's Domain cookie, say) and the server can't tell which is
    which — so the flow counts as unbound and the click has to be confirmed."""
    values = request.cookies.getlist(flow_cookie_name(name))
    if len(values) != 1:
        return None
    try:
        values[0].encode('utf-8')       # a mangled header can decode to lone surrogates
    except UnicodeEncodeError:
        return None
    return values[0]
```

# One button, no handle: the browser finds the passkey itself (discoverable
# credential). The challenge rides in the bb_passkey flow cookie (300 s, single

PASSKEY_FAIL = {'error': 'that passkey did not work'}


def _passkey_refuse(reason, handle='?'):
    if 'sign count' in reason.lower():
        reason += ' — possible cloned authenticator; the owner can remove it under settings'
    log.warning('passkey sign-in refused for @%s from %s: %s', handle, auth.client_ip(), reason)
    resp = jsonify(PASSKEY_FAIL)
    resp.status_code = 401
    return auth.clear_flow_cookie(resp, passkeys.COOKIE, path=auth.FLOW_PATH_API)


@bp.post('/passkey/begin')
def passkey_sign_in_begin():
    if not passkeys.available():
        return jsonify({'error': 'passkeys are not set up here'}), 503
    if request.host.split(':', 1)[0] != passkeys.rp_id():
        return jsonify({'error': 'passkeys work on ' + passkeys.rp_id() + ' only'}), 404
    con = db.connect()
    try:
        reason = auth.check_rate_limits(con)
    finally:
        con.close()
    if reason:
        log.warning('passkey begin rate limited from %s: %s', auth.client_ip(), reason)
        return jsonify({'error': reason}), 429
    challenge = passkeys.new_challenge()
    resp = jsonify({'options': json.loads(passkeys.authentication_options(challenge))})
    return auth.set_flow_cookie(resp, passkeys.COOKIE, passkeys.encode_challenge(challenge),
                                passkeys.FLOW_TTL_S, path=auth.FLOW_PATH_API)


@bp.post('/passkey/finish')
def passkey_sign_in_finish():
    if not passkeys.available():
        return jsonify({'error': 'passkeys are not set up here'}), 503
    con = db.connect()
    try:
        reason = auth.check_rate_limits(con)
        if reason:
            log.warning('passkey finish rate limited from %s: %s', auth.client_ip(), reason)
            return jsonify({'error': reason}), 429
        body = request.get_json(silent=True)
        cred = body.get('credential') if isinstance(body, dict) else None
        if not isinstance(cred, dict) or not isinstance(cred.get('id'), str) or len(cred['id']) > 1024:
            return _passkey_refuse('malformed body')
        challenge = passkeys.decode_challenge(auth.flow_value(passkeys.COOKIE))
        if challenge is None:
            return _passkey_refuse('no challenge cookie (expired, replayed or missing)')
        try:
            cred_id = base64.urlsafe_b64decode(cred['id'] + '=' * (-len(cred['id']) % 4))
        except (ValueError, TypeError):
            return _passkey_refuse('credential id is not base64url')
        row = db.passkey_by_credential_id(con, cred_id)
        if row is None:
            return _passkey_refuse('unknown credential')
        user = db.get_user(con, row['user_id'])
        if user is None:
            return _passkey_refuse('credential without a user')
        try:
            new_count = passkeys.verify_authentication(cred, challenge, row['public_key'], row['sign_count'])
        except passkeys.PasskeyError as e:
            return _passkey_refuse(str(e), user['handle'])
        uh = (cred.get('response') or {}).get('userHandle') if isinstance(cred.get('response'), dict) else None
        if uh:
            try:
                uh_bytes = base64.urlsafe_b64decode(uh + '=' * (-len(uh) % 4))
            except (ValueError, TypeError):
                uh_bytes = b''
            if uh_bytes != str(user['id']).encode('ascii'):
                return _passkey_refuse('user handle does not match the credential owner', user['handle'])
        db.touch_passkey(con, row['id'], new_count)
        auth.login(con, user)
    finally:
        con.close()
    log.info('passkey sign-in: @%s from %s (passkey %s)', user['handle'], auth.client_ip(), row['id'])
    resp = jsonify(auth.self_view(user))
    return auth.clear_flow_cookie(resp, passkeys.COOKIE, path=auth.FLOW_PATH_API)
