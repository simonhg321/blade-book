# The Vault (/me redesign) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `/me` from an admin list into "the vault": a beautiful private twin of the public register where the owner sees at a glance what's shown and what's private, and flips it with one tap.

**Architecture:** Static page `html/me/index.html` (vanilla JS, no framework, no `innerHTML`, CSP self-only) over the existing JSON API. Three steps, each shipped on its own: (1) the shelf, the grid that replaces the list, with today's card reused inside a sheet so no feature is lost; (2) a new knife sheet with per-photo public/private and add-a-photo-after-save; (3) "what my public page shows" switches wired into `bb/publish.py`. **This plan details Step 1. Steps 2 and 3 get their own plans once Step 1 is live and Simon has used it.**

**Tech Stack:** Flask API (unchanged in Step 1), vanilla JS, `html/vibe.css` tokens (cream `#faf6ee`, ink, rust accent `#b8452c`, ok green `#2c7a3f`, Bebas Neue + DM Sans self-hosted), pytest needle tests in `tests/test_deploy_files.py`, Playwright screenshots from a scratch venv with a stubbed API.

**Spec:** Simon approved mockup `https://blade-book.com/blade-book/abtesting/vault.html` (source kept at `docs/mockups/vault.html`), 2026-09-26 PDT: "Oh i like that mock up. Thats slick." Decisions: knives are born private (live, e5a78ed); the owner picks what goes public; the private side must be "very pleasing".

## Global Constraints

- No `innerHTML` anywhere in `html/me/index.html` (existing test `assert 'innerHTML' not in html`). Build DOM with `el()`.
- No third-party assets: fonts, images and scripts all from `/blade-book/…` (CSP `default-src 'self'`).
- Never add a CSS class to two unrelated elements and query it with `querySelector`. The `.hero` photo/button collision caused the silent K93 face pin (c0d01c3). Tile parts get `vt-`-prefixed classes.
- Keep every existing capability reachable: edit, sale, re-read, delete, face pin (with its confirm dialog), public toggle, bulk public/private, search incl. private notes, drafts, CSV export, covers link, public-page settings.
- Existing needle tests in `tests/test_deploy_files.py` for `/me` must keep passing (they pin wiring such as `featured_knife_id: pinned ? null : k.id`, `'<details class="more">'`, `openMap`, `window.scrollTo(0, y)`, `YOUR PUBLIC PAGE`, `id="pubsec"`).
- Static page only in Step 1: deploy is a `cp` into `/var/www/html/blade-book/me/` as shg. No app restart.
- Screenshot desktop (1440×900) and phone (390×844) before showing Simon.

## Review Focus

1. **A collector with 0 live knives and 1 draft**: the shelf must show the draft row and the add tile, never a blank page or a JS error.
2. **Filter "Private" with 0 private knives** shows "nothing here", not the whole list.

```js
  // --- the shelf (vault, 2026-09-26): what a collector reads on a tile ---
  function isShown(k) { return !!(k.status === 'live' && k.is_public && !k.hidden_at); }
  function shelfTitle(k) {
    var e = k.ext || {};
    var brand = (k.maker || 'crk') !== 'crk' && k.maker_name && (k.model || '').toLowerCase().indexOf(k.maker_name.split(' ')[0].toLowerCase()) === -1 ? k.maker_name : '';
    var main = [brand, e.size, k.model, e.generation].filter(Boolean).join(' ') || 'untitled';
    var flair = e.graphic_name || e.special_edition || k.variant || e.damascus_pattern || '';
    if (flair && main.toLowerCase().indexOf(String(flair).toLowerCase()) !== -1) flair = '';
    return [main, flair];
  }
  var MONTHS = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'];
  function bornLabel(k) {
    var b = k.born_on || ''; if (!b) return 'undated';
    var p = b.split('-');
    if (p.length >= 3) return 'born ' + MONTHS[+p[1] - 1] + ' ' + (+p[2]) + ', ' + p[0];
    if (p.length === 2) return 'born ' + MONTHS[+p[1] - 1] + ' ' + p[0];
    return 'born ' + p[0];
  }
  function shelfCounts(list) {
    var c = { all: 0, shown: 0, priv: 0, sale: 0 };
    list.forEach(function (k) { c.all++; if (isShown(k)) c.shown++; else c.priv++;
      if (k.sale_status === 'for_sale' || k.sale_status === 'for_trade') c.sale++; });
    return c;
  }
```
